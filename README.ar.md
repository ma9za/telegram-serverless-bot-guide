# بوت تلجرام من جوالك

بدون سيرفر ولا كمبيوتر ولا كود، تلجرام تستضيف البوت و Claude يكتبه وينشره

[English](README.md)

تلجرام صار عندها **Serverless** يعني بوتك يشتغل في سحابة تلجرام نفسها، ما تحتاج تستأجر سيرفر ولا تجهز webhook ولا تخلي شي شغال طول الوقت، و Claude يكتب الكود وينشره من داخل المحادثة يعني يكفيك جوالك

## وش يعني Serverless

- كودك يعيش في سحابة تلجرام ويشتغل بس لما أحد يكلم البوت
- كل بوت له قاعدة بيانات جاهزة بدون أي تركيب
- الميني اب يُستضاف عندهم برابط جاهز
- اللغة JavaScript بس ولا تشيل همها لأن الذكاء الاصطناعي هو اللي يكتبها

## ١ سوّ البوت

ادخل [@BotFather](https://t.me/BotFather) وارسل `/newbot` وعطه اسم ويوزر ينتهي بـ `bot`

## ٢ فعّل Serverless

في بوت فاذر افتح بوتك ثم **Settings** وبعدها **Serverless** وشغّل الزر

> أحيان تلجرام يطوّل شوي لين يوافق ويتفعّل، إذا ما اشتغل ارجع له بعدين

## ٣ انسخ مفاتيحك

بعد التفعيل ادخل **CLI Access** وانسخ شيئين

1. أمر الإنشاء وفيه اسم بوتك جاهز
   ```
   npm create @tgcloud/bot YourBotName
   ```
2. الـ **Access token**

> ⚠️ الـ Access token **غير توكن البوت العادي** اللي يعطيك إياه بوت فاذر أول ما تسوي البوت، وهو اللي نبيه هنا ولا تعطيه أحد

## ٤ خل Claude يوصل لتلجرام

من **claude.ai** افتح **Settings** ثم **Capabilities**

- فعّل **Allow network egress**
- اختر **All domains** في **Domain allowlist**

وبعدها **افتح محادثة جديدة** عشان يمشي عليها الإعداد، وهذا متاح في الاشتراك المدفوع

## ٥ برومبت واحد يبني كل شي

الصقه في المحادثة الجديدة وحط أمرك وتوكنك

</div>

```
ابنِ لي بوت تلجرام على تلجرام Serverless من الصفر
أمر الإنشاء: npm create @tgcloud/bot YourBotName
التوكن: الصق الـ Access token هنا
شغّل أمر الإنشاء واقرأ ملف AGENTS.md
لا تستخدم أمر login واستخدم بداله المتغير TGCLOUD_TOKEN ومعه NODE_USE_ENV_PROXY=1
خل البوت يرد على أي رسالة بـ «هلا والله» واسم الشخص وبعدها «حياك في البوت»
جربه وبعدها انشره على تلجرام
```

<div dir="rtl">

ليش البرومبت مكتوب كذا

- **AGENTS.md** ملف يجي مع المشروع يشرح للذكاء الاصطناعي قوانين المنصة كلها فيفهم الشغل من أول رسالة
- **TGCLOUD_TOKEN بدال login** لأن أمر login يوقف وينتظرك تكتب التوكن بيدك والذكاء الاصطناعي ما يقدر
- **NODE_USE_ENV_PROXY=1** لأن Claude يطلع للإنترنت عن طريق بروكسي و Node ما يستخدمه لحاله، وبدونه النشر ما يوصل

## ٦ جربه

ادخل بوتك وارسل `/start` ويرد عليك «هلا والله تركي 👋 حياك في البوت»

بوتك الحين شغّال 24 ساعة عند تلجرام حتى لو قفلت المحادثة، وأي تعديل بعدها قوله لـ Claude وهو ينشره

## الميني اب

في بوت فاذر تحت Serverless فيه **Mini App Files** وبيكون فاضي لين ترفع الواجهة، قل لـ Claude بنفس المحادثة

</div>

```
سوّ لي ميني اب بسيط يرحب بالمستخدم باسمه وارفعه مع البوت وخل زر القائمة في البوت يفتحه
```

## تبي تشتغل من جهازك؟

نفس الطريقة تمشي مع **Claude Code** أو **Codex** على جهازك أو سيرفرك، تثبّت واحد منهم وتعطيه نفس البرومبت، والأوامر موجودة في [النسخة الإنجليزية](README.md#prefer-your-own-machine)

## وبعدها

الحين عندك الأساس، والباقي كله كلام تقوله للذكاء الاصطناعي: أزرار وقوائم، قاعدة بيانات، متجر، ألعاب، اشتراكات بالنجوم، لوحة تحكم

- الشرح الرسمي [core.telegram.org/bots/serverless](https://core.telegram.org/bots/serverless)
- أمثلة جاهزة [mititgcloudbot](https://github.com/tiennm99dev/mititgcloudbot) و [telegram-bot-serverless](https://github.com/RSaied/telegram-bot-serverless)
